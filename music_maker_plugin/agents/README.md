# Thư mục Agents chuyên môn (`agents/`)

Đây là nơi đặt các specialist agent (ví dụ: chuyên gia trống/groove, chuyên gia hòa âm piano, chuyên gia mixing/stem...) trong các phiên bản mở rộng sau này của `music_maker_plugin`.

Khi plugin được kích hoạt:
- `soundfont-music` luôn là skill điều phối chính.
- Tất cả các skill trong `skills/` và các agent chuyên môn được bổ sung trong `agents/` sẽ được kích hoạt đồng bộ theo quy tắc tại `rules/AGENTS.md`.
